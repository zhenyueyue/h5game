# 艾泽兰契约 · 永夜女神录

第一章可玩的 H5 放置卡牌游戏。手机竖屏用触控操作，电脑网页支持鼠标和数字键 1–7。两端使用同一套游戏规则，进度保存在当前浏览器。

手机从圣堂进入游戏，底部可切换圣堂、战役、英雄、召唤与圣匣。战役页可打开章节地图和七人布阵。点按两个站位交换英雄。电脑端可在左侧直接进入七个页面，战场右侧显示关卡情报、首通奖励和元素克制。

## 运行

```sh
npm run build
npm start
npm test
```

预览地址为 [127.0.0.1:5173](http://127.0.0.1:5173/)。构建产物 `dist/index.html` 包含全部代码和美术资源，可直接上传到静态托管服务。源码与构建无需安装 npm 包。

## 首章提示

通关 1-3 后去召唤页，用 8 张契约券进行首十连。通关 1-4 后在英雄页面为小队一键换装。挑战 1-10 时关闭 AUTO，看到「永夜裁决蓄力」再点贞德释放护盾。

## 元素克制

光暗互克。其余元素依次为水克火、火克风、风克地、地克雷、雷克水。普攻和有伤害的奥义命中被克制的目标时，基础伤害提高 20%，常规暴击率提高 15 个百分点。

| 角色 | 元素 | 定位 |
| --- | --- | --- |
| 贞德 | 光 | 群体守护 |
| 芙蕾雅 | 火 | 前排破甲 |
| 卡蜜拉 | 雷 | 攻转护盾 |
| 菲奥娜 | 水 | 群体冻结 |
| 伊莉丝 | 地 | 回复充能 |
| 希尔薇 | 风 | 残血收割 |
| 薇拉 | 暗 | 后排断招 |

## 美术资源

界面以墨紫、冷月光和暖金为主。内置 ImageGen 参考双端战场设计稿绘制七名英雄和首领赫尔薇尔。英雄在战斗中使用圆润的大头 Q 版，卡面突出眼睛、发型和服装色。

英雄页的「插画鉴赏」收录七名英雄及赫尔薇尔的竖幅插画。可点按头像或按左右方向键切换，包括尚未契约的角色。插画由内置 ImageGen 绘制，每张都有单独的场景、成年角色比例和动作构图。服装采用贴身剪裁，并按人物配过膝袜、吊带袜或渔网袜。

每幅插画由同为 1024 × 1536 的透明人物层 `assets/gallery-figure-*.webp` 和独立空景 `assets/gallery-scene-*.webp` 叠放。人物层包含随手持武器和披风等随身部件，前端可单独对 `.illustration-figure` 应用变换。头像、卡面和战斗素材位于 `assets/gothic-*.webp`。资源构建时嵌入单文件游戏。
